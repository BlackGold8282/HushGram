# Call sites a patched Instagram must have, checked across every dex of the APK by DexDiff.java.
#   single-call <method reference> in <caller method name>
#   first-call <method reference> on <class>
#   first-call <method reference> on-type-named <GraphQL type>
#   first-call <method reference> outside <package prefix>
#   start-call <method reference> [in [static|instance] <(parameters)return, * for any run>] holding <string> [<string> ...]
#   no-call <method reference> outside <package prefix>
#   next-call <method reference> after <method reference> [in [static|instance] <shape>] holding <string> [<string> ...]
#   sole-call <method reference> replacing <method reference> [in [static|instance] <shape>] holding <string> [<string> ...]
#   once-call <method reference> [in [static|instance] <shape>] holding <string> [<string> ...]
#   shared-call <method reference> [in [static|instance] <shape>] holding <string> [<string> ...]
# A start-call, next-call, sole-call, once-call or shared-call rule picks its method by every string
# it names and its shape, and exactly one of Instagram's methods may answer that; name as much as the
# patch's own fingerprint finds the method by. A string with a space in it is written with \s for
# each space, and a backslash as \\. A string written as a field reference (Lclass;->name:type) is
# held by a method that reads or writes that field, for a method that loads no string of its own.
# For a method that holds neither, any of the five may say class-holding in place of holding: the
# strings are then its class's, held by its methods between them, and the method is the one of the
# shape in such a class. A * inside a class name stays in that name, so (L*;)V takes one object.
#
# One guard per hot method. A guard the patch puts first in a method gets a start-call rule, which
# holds it first there and in no other method holding the same strings, and a once-call rule, which
# holds it to one call in that method and none anywhere else. start-call alone passes a guard
# written in twice, since the first of the two is still first.
#
# The patch fingerprint picks the method that puts a sponsored item into a feed by
# "cross_surface_duplicate_ad" and "Is ad pod", a static method answering a boolean. "Is ad pod" has
# a space, so the rule names the other string and the shape: of the four methods holding it on 449,
# one is static and answers a boolean. Left out, every ad goes in; twice or elsewhere, it's no
# longer the guard Hide ads wrote.
start-call Lapp/hushgram/extension/instagram/ads/Ads;->hide()Z in static (*)Z holding cross_surface_duplicate_ad
once-call Lapp/hushgram/extension/instagram/ads/Ads;->hide()Z in static (*)Z holding cross_surface_duplicate_ad
